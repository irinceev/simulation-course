# Лабораторная работа  
## Система массового обслуживания M/M/1/0 (с отказами)

---

## 1. Описание задачи

В работе моделируется простейшая система массового обслуживания **M/M/1/0**.

Система состоит из:
- одного обслуживающего канала (1 сервер),
- пуассоновского потока заявок,
- экспоненциального времени обслуживания,
- отсутствия очереди (заявки теряются при занятости сервера).

---

## 2. Параметры модели

| Параметр | Значение | Описание |
|----------|----------|----------|
| λ | 4.0 | Интенсивность поступления заявок |
| μ | 3.0 | Интенсивность обслуживания |
| ρ = λ/μ | 1.33 | Коэффициент загрузки системы |
| T | 1000 | Время моделирования |

---

## 3. Теоретические формулы

Для системы M/M/1/0 используются следующие выражения:

### Коэффициент загрузки:
\[
\rho = \frac{\lambda}{\mu}
\]

---

### Вероятность того, что система свободна:
$$ P_0 = \frac{1}{1 + \rho} = \frac{1}{0.999} \approx 0.5003 $$

### Вероятность отказа:
$$ P_1 = \frac{\rho}{1 + \rho} = \frac{0.999}{1.999} \approx 0.4997 $$


## 4. Реализация модели

Модель реализована методом **дискретно-событийного моделирования**.

### Основная идея:

Система не идёт по шагам времени, а перескакивает между событиями:
- приход заявки
- завершение обслуживания

---

## 5. Алгоритм работы программы

1. Генерируется время до первой заявки  
2. Если сервер свободен — заявка обслуживается  
3. Если сервер занят — заявка теряется  
4. Генерируется время обслуживания  
5. Система выбирает ближайшее событие:
   - приход заявки
   - конец обслуживания  
6. Время модели прыгает к событию  
7. Процесс повторяется до T  

---

## 6. Результаты моделирования

Программа выводит:

- общее число заявок
- число отказов
- вероятность свободного состояния системы
- вероятность отказа
