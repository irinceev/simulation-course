## Теоретические сведения

### Марковский процесс с непрерывным временем

**Марковский процесс с непрерывным временем** — случайный процесс $X(t)$, для которого будущее состояние зависит только от настоящего и не зависит от прошлого:

$$P(X(t_{n+1}) = j \mid X(t_n) = i,\; X(t_{n-1}), \ldots, X(t_0)) = P(X(t_{n+1}) = j \mid X(t_n) = i)$$

### Матрица интенсивностей Q

Процесс задаётся **матрицей интенсивностей переходов** $Q = [q_{ij}]$, где:

- $q_{ij} \geq 0$ при $i \neq j$ — интенсивность перехода из состояния $i$ в состояние $j$
- $q_{ii} = -\displaystyle\sum_{j \neq i} q_{ij}$ — интенсивность ухода из состояния $i$ (диагональный элемент)

**Ключевое свойство:** сумма каждой строки равна нулю:

$$\sum_{j=1}^{n} q_{ij} = 0, \quad \forall i$$

### Время пребывания в состоянии

Время пребывания в состоянии $i$ распределено **экспоненциально** с параметром $\lambda_i = |q_{ii}|$:

$$f(\tau) = \lambda_i \, e^{-\lambda_i \tau}, \quad \tau \geq 0$$

**Математическое ожидание:**

$$M[\tau_i] = \frac{1}{\lambda_i} = \frac{1}{|q_{ii}|}$$

Экспоненциальное распределение обладает свойством **отсутствия памяти**:

$$P(\tau > t + s \mid \tau > s) = P(\tau > t)$$

Именно это свойство обеспечивает марковость процесса в непрерывном времени.

### Вероятности переходов

При выходе из состояния $i$ вероятность перехода в состояние $j$ пропорциональна интенсивности:

$$p_{ij} = \frac{q_{ij}}{\lambda_i} = \frac{q_{ij}}{|q_{ii}|}, \quad j \neq i$$

### Стационарное распределение

**Стационарное распределение** $\pi = [\pi_1, \pi_2, \pi_3]$ — вектор долей времени, проводимых в каждом состоянии в долгосрочной перспективе. Определяется из системы:

$$\pi Q = 0, \qquad \sum_{i=1}^{n} \pi_i = 1$$

Это эквивалентно нахождению собственного вектора транспонированной матрицы $Q^T$ для собственного значения $\lambda = 0$:

$$Q^T \pi^T = 0$$

### Метод обратного преобразования

Для генерации случайной величины с заданным дискретным распределением используется **метод обратного преобразования**: генерируется $U \sim \mathrm{Uniform}[0,1]$, затем перебираются состояния с накоплением кумулятивной суммы вероятностей — возвращается первое состояние, где накопленная сумма превысила $U$.

Для непрерывного случая (экспоненциальное распределение) метод даёт формулу:

$$\tau = -\frac{\ln U}{\lambda}$$

## Реализация

### Архитектура программы

Программа реализована в одном файле `weather_markov.py` и состоит из двух классов:

- `WeatherMarkovEngine` — математический движок: хранит матрицу Q, историю переходов, реализует шаг симуляции и статистические вычисления
- `WeatherApp` — графический интерфейс на tkinter с четырьмя графиками matplotlib

### Построение матрицы Q

Пользователь вводит только **внедиагональные** интенсивности $\lambda_{ij}$. Диагональ вычисляется автоматически как минус сумма строки — это исключает ошибку ввода некорректной матрицы:

```python
def _build_Q(self):
    Q = self._rates.copy()               # внедиагональные λ_ij
    np.fill_diagonal(Q, -Q.sum(axis=1)) # q_ii = −∑ q_ij
    self.Q = Q
```

### Генерация одного перехода — `step()`

```python
def step(self):
    s = self.current_state - 1
    lambda_total = abs(self.Q[s, s])          # интенсивность ухода
    if lambda_total < 1e-12:                  # защита: поглощающее состояние
        return self.current_state, 1.0

    # Время пребывания: τ ~ Exp(λ)
    # Внутри реализовано как −ln(U)/λ, U ~ Uniform(0,1]
    duration = random.expovariate(lambda_total)

    # Дискретизация для отображения на графике
    start_day = int(self.current_day)
    end_day   = int(self.current_day + duration)
    for d in range(start_day, end_day + 1):
        self.day_history.append((d, self.current_state))

    # Фиксируем переход ДО смены состояния
    self.history.append((self.current_state, duration))
    self.current_day += duration

    # Формируем кандидатов для метода обратного преобразования
    r2 = self._rates[s].copy()
    r2[s] = 0
    total = r2.sum()
    candidates = [
        (state_idx + 1, r2[state_idx] / total)
        for state_idx in range(3)
        if state_idx != s
    ]

    next_s = self._choose_next_state(candidates)
    self.current_state = next_s
    return next_s, duration
```

### Метод обратного преобразования — `_choose_next_state()`

Вместо стандартного `np.random.choice` выбор следующего состояния реализован вручную через метод обратного преобразования. Генерируется $U \sim \mathrm{Uniform}[0,1]$, затем перебираются пары $(j,\, p_{ij})$ с накоплением кумулятивной суммы:

```python
@staticmethod
def _choose_next_state(candidates):
    rand_val   = random.random()   # U ~ Uniform[0, 1]
    cumulative = 0.0
    for state, prob in candidates:
        cumulative += prob
        if cumulative >= rand_val:
            return state
    return candidates[-1][0]       # защита от ошибок округления float
```

**Пример** для состояния Ясно, `candidates = [(2, 0.6), (3, 0.4)]`:

| $U$  | Итерация 1: cumul = 0.6 | Итерация 2: cumul = 1.0 | Результат  |
|------|-------------------------|-------------------------|------------|
| 0.45 | 0.6 ≥ 0.45 → **стоп**  | —                       | 2 (Облачно)|
| 0.73 | 0.6 ≥ 0.73? нет         | 1.0 ≥ 0.73 → **стоп**  | 3 (Пасмурно)|

### Вычисление стационарного распределения

Решение $\pi Q = 0$ эквивалентно поиску собственного вектора $Q^T$ для $\lambda = 0$:

```python
def get_stationary(self):
    eigenvalues, eigenvectors = np.linalg.eig(self.Q.T)
    idx = np.argmin(np.abs(eigenvalues))  # λ ближайшее к нулю
    pi  = np.real(eigenvectors[:, idx])   # отбрасываем мнимую часть (погрешность)
    return pi / pi.sum()                  # нормировка до суммы = 1
```

### Вычисление эмпирического распределения

Эмпирическая оценка доли времени в состоянии $i$ (Алгоритм 2 из курса):

$$\hat{\pi}_i = \frac{\displaystyle\sum_{k:\, s_k = i} \tau_k}{\displaystyle\sum_{k=1}^{N} \tau_k}$$

```python
def get_empirical(self):
    total = sum(d for _, d in self.history)
    times = [0.0, 0.0, 0.0]
    for s, d in self.history:
        times[s-1] += d
    return np.array(times) / total
```

### Кумулятивное распределение (сходимость)

После каждого перехода пересчитываются текущие доли — массив формы $(N \times 3)$ для графика сходимости:

```python
def get_cumulative(self):
    cum  = []
    runs = [0.0, 0.0, 0.0]
    tot  = 0.0
    for s, d in self.history:
        runs[s-1] += d
        tot        += d
        cum.append([runs[0]/tot, runs[1]/tot, runs[2]/tot])
    return np.array(cum)
```

## Результаты моделирования

### Теоретическое стационарное распределение

Для заданной матрицы $Q$ решение системы $\pi Q = 0$ даёт:

$$\pi = (\pi_1,\, \pi_2,\, \pi_3) = \left(\frac{1}{3},\, \frac{1}{3},\, \frac{1}{3}\right) \approx (0.333,\, 0.333,\, 0.333)$$

**Интерпретация:** в долгосрочной перспективе система проводит равные доли времени в каждом из трёх состояний. Это результат конкретных числовых значений матрицы, а не общее правило — при иных интенсивностях $\pi_i$ будут различаться.

### Теоретическое среднее время одного пребывания

$$M[\tau] = \sum_{i=1}^{3} \pi_i \cdot \frac{1}{|\lambda_i|} = \frac{1}{3} \cdot 2{,}00 + \frac{1}{3} \cdot 1{,}43 + \frac{1}{3} \cdot 2{,}00 \approx 1{,}81 \text{ дня}$$

$$\lim_{T \to \infty} \frac{1}{T} \int_0^T \mathbf{1}\{X(t) = i\}\, dt = \pi_i$$

## Визуализация результатов

Программа строит четыре графика в реальном времени в процессе симуляции:

### 1. Непрерывный поток состояний

Ступенчатый график последних 60 переходов с раскраской фона по состояниям (жёлтый — Ясно, синий — Облачно, серый — Пасмурно). Ось абсцисс — суммарное время в днях (непрерывное), ось ординат — номер состояния.

### 2. Эмпирика vs Теория

Сдвоенная столбчатая диаграмма: для каждого состояния рядом стоят эмпирическая доля времени (сплошной столбец) и теоретическая $\pi_i$ (заштрихованный). Числовые значения подписаны над столбцами.

### 3. Матрица интенсивностей (тепловая карта)

Визуализация матрицы $Q$ в виде heatmap с палитрой `RdYlGn`:
- Тёплые цвета — положительные интенсивности переходов
- Холодные цвета — отрицательная диагональ

### 4. Сходимость к стационарному распределению

График кумулятивных долей времени от числа переходов. Три кривые (по одной на состояние) постепенно выходят на горизонтальные пунктирные асимптоты — теоретические значения $\pi_i$.

## Особенности реализации

### Автоматическое вычисление диагонали

В отличие от наивной реализации, где пользователь вводит все 9 элементов матрицы (включая диагональ), в данной программе вводятся только **6 внедиагональных** интенсивностей. Диагональ вычисляется автоматически в `_build_Q()`. Это устраняет класс ошибок, когда введённая диагональ не соответствует условию $\sum_j q_{ij} = 0$.

### Метод обратного преобразования вместо `np.random.choice`

Выбор следующего состояния реализован через `_choose_next_state()` — ручную реализацию метода обратного преобразования. Математически эквивалентен `np.random.choice(..., p=probabilities)`, но явно демонстрирует алгоритм: кумулятивное суммирование вероятностей и сравнение с $U \sim \mathrm{Uniform}[0,1]$.

### Дискретизация дней для отображения

Математическое время в модели непрерывно. Для корректного отображения на ступенчатом графике каждый интервал `[current_day, current_day + duration]` разбивается на целые дни и записывается в `day_history`. Это не влияет на математику — только на визуализацию.

### Нецикличный планировщик tkinter

Анимация реализована через `root.after(delay, _loop)` — не отдельный поток, а планировщик событий tkinter. Функция ставит саму себя в очередь через `delay` мс. Графики обновляются раз в 5 переходов (`history % 5 == 0`) для снижения нагрузки на перерисовку matplotlib.

## Вывод

В ходе лабораторной работы реализована модель марковского процесса с непрерывным временем на примере изменения погоды с тремя состояниями. Основные результаты:

1. **Корректность алгоритма.** Время пребывания генерируется из показательного распределения $\mathrm{Exp}(\lambda_i)$, следующее состояние выбирается пропорционально интенсивностям переходов методом обратного преобразования. Алгоритм точно воспроизводит свойства ЦМНВ.

2. **Соответствие стационарному распределению.** При $N \geq 100$ переходах эмпирические доли времени сходятся к теоретическому стационарному распределению $\pi = (1/3,\, 1/3,\, 1/3)$, полученному аналитически из $\pi Q = 0$ через собственные векторы $Q^T$.

3. **Сходимость эмпирических характеристик.** С увеличением $N$ относительные погрешности монотонно убывают, что подтверждает эргодическое свойство марковского процесса. График кумулятивного распределения наглядно демонстрирует эту сходимость.

4. **Среднее время пребывания.** Эмпирическое среднее ($\approx 1.77$ дня при $N = 10\,000$) приближается к теоретическому $\approx 1.81$ дня, вычисленному как $\sum_i \pi_i / \lambda_i$.

5. **Качество реализации.** Автоматическое вычисление диагонали исключает ввод некорректной матрицы Q. Метод обратного преобразования реализован явно, что соответствует алгоритмам, изученным в курсе.
